# Governance

AerolVM is maintained by the people listed in [CODEOWNERS](.github/CODEOWNERS). Decisions about what merges are made in pull requests. The default branch ruleset requires one approving review from a code owner who is not the pull request author, dismisses that approval when new commits are pushed, and requires approval of the last push before merge.

## Granting write access

Code collaborators must be reviewed and approved prior to receiving write access to the repository, release credentials, or any other sensitive resource. A repository administrator performs that review. Write access, maintainer role, and access to release or registry credentials are not granted on request alone.
