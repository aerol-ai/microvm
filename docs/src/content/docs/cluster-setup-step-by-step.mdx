description: Guided checklist for bootstrapping a 3-node or custom AerolVM cluster.

A guided walkthrough that turns a fleet of single-node installs into an AerolVM
cluster. Pick your topology, work through the checklist, and tick each step as
you finish it — progress is remembered on this device.

For the full reference (every env var, quorum math, lost-quorum recovery,
backup/restore) see [Cluster Setup](/cluster-setup).

<section data-cs-panel="three" class="cs-panel">

### Assumptions

- You have **3 Linux hosts** with low-latency private connectivity between them.
- One host is designated the **seed**; the other two will join it.
- All 3 nodes will run the **`mixed` role** (Raft voter + worker + ingress on
  every node). This is the right default up to about 10 nodes — see
  [Cluster Ingress](/cluster-ingress) for when to split roles.
- You have an SDK / operator PAT token chosen in advance; the same
  `SB_PAT_TOKEN` value will be used on every node.

<div class="cs-steps" data-cs-steps="three">

<div class="cs-step" data-cs-step-id="three-1">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 1 — Install single-node AerolVM on all 3 hosts</span>
  </label>
<div class="cs-step-body">

On **each** of the 3 nodes, run the standard single-node installer with the
**same** PAT token:

```bash
curl -fsSL https://github.com/aerol-ai/microvm/releases/latest/download/install.sh \
  | sudo bash -s -- --pat-token <shared-pat-token>
```

Cluster-internal raft writes that get forwarded between nodes authenticate with
this token, so every node must hold the same value.

</div>
</div>

<div class="cs-step" data-cs-step-id="three-2">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 2 — Open the cluster-internal ports between the 3 nodes</span>
  </label>
<div class="cs-step-body">

Allow these ports **between the cluster nodes only**, never from the public
internet:

- `7000/TCP` — raft replication.
- `7001/TCP` and `7001/UDP` — SWIM gossip.
- `7002/TCP` — cluster-internal mTLS (raft applies + owner API forwarding).

A typical UFW rule per node, allowing the other two nodes by IP:

```bash
sudo ufw allow from <other-node-ip> to any port 7000 proto tcp
sudo ufw allow from <other-node-ip> to any port 7001
sudo ufw allow from <other-node-ip> to any port 7002 proto tcp
```

</div>
</div>

<div class="cs-step" data-cs-step-id="three-3">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 3 — Bootstrap the seed node</span>
  </label>
<div class="cs-step-body">

On the seed host only:

```bash
curl -fsSL https://github.com/aerol-ai/microvm/releases/latest/download/cluster-init.sh \
  | sudo bash
```

The script auto-generates a gossip key, writes
`/etc/sandboxd/cluster.env` + a systemd drop-in, restarts `sandboxd`, and
prints two artefacts you must keep:

1. The **gossip key** — needed by every joining node, only printed once.
2. The **TLS + credential bundle** at `aerolvm-tls-bundle.tar.gz` — holds the
   cluster CA and the shared credential-encryption key.

</div>
</div>

<div class="cs-step" data-cs-step-id="three-4">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 4 — Copy the gossip key and bundle to the other 2 nodes</span>
  </label>
<div class="cs-step-body">

Transfer over a secure channel (`scp`, vault, etc.) — anyone with the bundle
can mint a node cert and join the cluster, and anyone with the credential key
can decrypt every sandbox's sealed credentials.

```bash
scp aerolvm-tls-bundle.tar.gz user@<node-2>:/tmp/
scp aerolvm-tls-bundle.tar.gz user@<node-3>:/tmp/
```

Note the gossip key separately (e.g. paste it into your password manager); the
join script will ask for it.

</div>
</div>

<div class="cs-step" data-cs-step-id="three-5">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 5 — Join nodes 2 and 3 to the cluster</span>
  </label>
<div class="cs-step-body">

On **each** of the other 2 nodes:

```bash
curl -fsSL https://github.com/aerol-ai/microvm/releases/latest/download/cluster-join.sh \
  | sudo bash -s -- \
    --gossip-key '<key-from-step-3>' \
    --peers <seed-ip>:7001 \
    --tls-bundle /tmp/aerolvm-tls-bundle.tar.gz
```

The leader auto-promotes new members to raft voters until the voter cap
(`SB_CLUSTER_MAX_AUTO_VOTERS`, default 5) is hit. With 3 nodes you'll end up
with 3 voters — the recommended minimum for production.

</div>
</div>

<div class="cs-step" data-cs-step-id="three-6">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 6 — Verify cluster health</span>
  </label>
<div class="cs-step-body">

Tail the seed's daemon log and watch for `cluster: auto-promoted member to
raft voter` lines as each joiner lands:

```bash
sudo journalctl -u sandboxd -f
```

Then confirm membership and leader from any node:

```bash
curl -s -H "Authorization: Bearer $SB_PAT_TOKEN" \
  http://127.0.0.1:21212/v1/cluster/members
curl -s -H "Authorization: Bearer $SB_PAT_TOKEN" \
  http://127.0.0.1:21212/v1/cluster/leader
```

You should see all 3 node IDs with `alive: true`, and a non-empty `Leader`.

</div>
</div>

</div>

<div class="cs-step" data-cs-step-id="custom-1">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 1 — Sanity-check the topology</span>
  </label>
<div class="cs-step-body">

You picked **<span data-cs-ph="servers">3</span> server**,
**<span data-cs-ph="workers">5</span> worker**, and
**<span data-cs-ph="ingress">2</span> ingress** nodes
(<span data-cs-ph="total">10</span> total).

Recommended sanity rules:

- Run an **odd** number of servers (3, 5, 7). Even counts raise the quorum
  threshold without raising fault tolerance.
- For production, use **at least 3 servers**. A single server is fine for
  staging but any restart blocks writes briefly.
- **At least 2 ingress** nodes if you want failover at the public edge.
- Workers can scale freely — they join as raft non-voters.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-2">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 2 — Pick the public ingress address</span>
  </label>
<div class="cs-step-body">

The <span data-cs-ph="ingress">2</span> ingress nodes will sit behind a single
advertised hostname that the SDK and end users hit. Pick one of:

- **DNS round-robin** — `A`/`AAAA` records pointing at every ingress IP.
- **Cloud TCP LB** — AWS NLB, GCP TCP LB, Cloudflare Spectrum.
- **MetalLB / BGP VIP** — bare-metal / on-prem.

Decide the hostname now; you'll pass it as `--ingress-advertise-host` to the
cluster scripts. See [Cluster Ingress](/cluster-ingress) for the trade-offs.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-3">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 3 — Install single-node AerolVM on all <span data-cs-ph="total">10</span> hosts</span>
  </label>
<div class="cs-step-body">

On **every** node (server, worker, ingress), with the **same** PAT token:

```bash
curl -fsSL https://github.com/aerol-ai/microvm/releases/latest/download/install.sh \
  | sudo bash -s -- --pat-token <shared-pat-token>
```

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-4">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 4 — Open cluster ports between every pair of nodes</span>
  </label>
<div class="cs-step-body">

Across all <span data-cs-ph="total">10</span> nodes, allow these ports on the
cluster-private network only:

- `7000/TCP` (raft), `7001/TCP+UDP` (gossip), `7002/TCP` (internal mTLS).

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-5">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 5 — Bootstrap the first server node</span>
  </label>
<div class="cs-step-body">

Pick one server host as the seed and run:

```bash
sudo ./cluster-init.sh \
    --role server \
    --ingress-advertise-host <hostname-from-step-2> \
    --gossip-key "$(openssl rand -base64 32)"
```

Save the printed gossip key and the `aerolvm-tls-bundle.tar.gz` bundle — every
other node needs both.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-6">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 6 — Join the remaining <span data-cs-ph="serversMinusOne">2</span> server nodes</span>
  </label>
<div class="cs-step-body">

On each of the other server hosts:

```bash
sudo ./cluster-join.sh \
    --role server \
    --ingress-advertise-host <hostname-from-step-2> \
    --gossip-key '<key>' \
    --peers '<seed-ip>:7001' \
    --tls-bundle /tmp/aerolvm-tls-bundle.tar.gz
```

All <span data-cs-ph="servers">3</span> server nodes should now show in
`/v1/cluster/members` before continuing.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-7">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 7 — Join the <span data-cs-ph="workers">5</span> worker nodes</span>
  </label>
<div class="cs-step-body">

On each worker host:

```bash
sudo ./cluster-join.sh \
    --role worker \
    --ingress-advertise-host <hostname-from-step-2> \
    --gossip-key '<key>' \
    --peers '<seed-ip>:7001' \
    --tls-bundle /tmp/aerolvm-tls-bundle.tar.gz
```

Workers join as raft non-voters: they own sandboxes and forward writes, but
they don't count toward quorum, so scaling them out is cheap.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-8">
  <label class="cs-step-head">
    <input type="checkbox" data-cs-check />
    <span class="cs-step-title">Step 8 — Join the <span data-cs-ph="ingress">2</span> ingress nodes</span>
  </label>
<div class="cs-step-body">

On each ingress host:

```bash
sudo ./cluster-join.sh \
    --role ingress \
    --ingress-advertise-host <hostname-from-step-2> \
    --gossip-key '<key>' \
    --peers '<seed-ip>:7001' \
    --tls-bundle /tmp/aerolvm-tls-bundle.tar.gz
```

Then point your DNS / cloud LB / MetalLB VIP from step 2 at these
<span data-cs-ph="ingress">2</span> public IPs.

</div>
</div>

<div class="cs-step" data-cs-step-id="custom-9">

    <span class="cs-step-title">Step 9 — Verify cluster health</span>

<div class="cs-step-body">

From any node:

```bash
curl -s -H "Authorization: Bearer $SB_PAT_TOKEN" \
  http://127.0.0.1:21212/v1/cluster/members
curl -s -H "Authorization: Bearer $SB_PAT_TOKEN" \
  http://127.0.0.1:21212/v1/cluster/leader
```

You should see <span data-cs-ph="total">10</span> nodes with `alive: true`,
each with its declared role, and a non-empty `Leader` (one of the
<span data-cs-ph="servers">3</span> server nodes). Done — point an SDK at the
ingress hostname and create your first cluster sandbox.

</div>

<script is:inline>{`
  (function () {
    var STORAGE_KEY = 'aerolvm-cluster-progress';
    var TOPOLOGY_KEY = 'aerolvm-cluster-topology';

    function readProgress() {
      try {
        var raw = localStorage.getItem(STORAGE_KEY);
        if (!raw) return { three: {}, custom: {} };
        var parsed = JSON.parse(raw);
        return {
          three: parsed.three || {},
          custom: parsed.custom || {},
        };
      } catch (e) {
        return { three: {}, custom: {} };
      }
    }

    function writeProgress(progress) {
      try {
        localStorage.setItem(STORAGE_KEY, JSON.stringify(progress));
      } catch (e) {
        /* storage full or disabled, ignore */
      }
    }

    function topologyOf(stepEl) {
      var stepsContainer = stepEl.closest('[data-cs-steps]');
      return stepsContainer ? stepsContainer.getAttribute('data-cs-steps') : null;
    }

    function applyProgress() {
      var progress = readProgress();
      var steps = document.querySelectorAll('.cs-step');
      for (var i = 0; i < steps.length; i++) {
        var step = steps[i];
        var topology = topologyOf(step);
        var id = step.getAttribute('data-cs-step-id');
        var done = topology && progress[topology] && progress[topology][id] === true;
        var checkbox = step.querySelector('input[data-cs-check]');
        if (checkbox) checkbox.checked = !!done;
        step.setAttribute('data-cs-complete', done ? 'true' : 'false');
      }
    }

    function wireCheckboxes() {
      var checkboxes = document.querySelectorAll('input[data-cs-check]');
      for (var i = 0; i < checkboxes.length; i++) {
        checkboxes[i].addEventListener('change', function (event) {
          var step = event.target.closest('.cs-step');
          if (!step) return;
          var topology = topologyOf(step);
          var id = step.getAttribute('data-cs-step-id');
          if (!topology || !id) return;
          var progress = readProgress();
          progress[topology][id] = !!event.target.checked;
          writeProgress(progress);
          step.setAttribute('data-cs-complete', event.target.checked ? 'true' : 'false');
        });
      }
    }

    function showPanel(topology) {
      var panels = document.querySelectorAll('[data-cs-panel]');
      for (var i = 0; i < panels.length; i++) {
        var match = panels[i].getAttribute('data-cs-panel') === topology;
        if (match) panels[i].removeAttribute('hidden');
        else panels[i].setAttribute('hidden', '');
      }
      try { localStorage.setItem(TOPOLOGY_KEY, topology); } catch (e) {}
    }

    function wireSelect() {
      var select = document.getElementById('cs-topology');
      if (!select) return;
      var saved = null;
      try { saved = localStorage.getItem(TOPOLOGY_KEY); } catch (e) {}
      if (saved === 'three' || saved === 'custom') select.value = saved;
      showPanel(select.value);
      select.addEventListener('change', function () { showPanel(select.value); });
    }

    function updatePlaceholders(values) {
      var nodes = document.querySelectorAll('[data-cs-ph]');
      for (var i = 0; i < nodes.length; i++) {
        var key = nodes[i].getAttribute('data-cs-ph');
        if (key in values) nodes[i].textContent = String(values[key]);
      }
    }

    function buildWarning(servers, ingress) {
      var msgs = [];
      if (servers < 3) msgs.push('Only ' + servers + ' server: any restart blocks writes, any disk loss is total.');
      else if (servers % 2 === 0) msgs.push(servers + ' is an even voter count — prefer 3, 5, or 7 (same fault tolerance, lower quorum).');
      if (ingress < 1) msgs.push('0 ingress nodes: public traffic has nowhere to land. Add at least 1.');
      return msgs.join(' ');
    }

    function renderCustom(servers, workers, ingress) {
      var values = {
        servers: servers,
        workers: workers,
        ingress: ingress,
        total: servers + workers + ingress,
        serversMinusOne: Math.max(0, servers - 1),
      };
      updatePlaceholders(values);

      var summary = document.querySelector('[data-cs-custom-summary]');
      var steps = document.querySelector('[data-cs-steps="custom"]');
      if (summary) summary.removeAttribute('hidden');
      if (steps) steps.removeAttribute('hidden');

      var warn = document.querySelector('[data-cs-warn]');
      if (warn) {
        var msg = buildWarning(servers, ingress);
        if (msg) { warn.textContent = msg; warn.removeAttribute('hidden'); }
        else { warn.setAttribute('hidden', ''); warn.textContent = ''; }
      }
    }

    function readForm(form) {
      var data = new FormData(form);
      return {
        servers: Math.max(1, parseInt(data.get('servers') || '0', 10) || 0),
        workers: Math.max(0, parseInt(data.get('workers') || '0', 10) || 0),
        ingress: Math.max(0, parseInt(data.get('ingress') || '0', 10) || 0),
      };
    }

    function wireCustomForm() {
      var form = document.getElementById('cs-custom-form');
      if (!form) return;
      form.addEventListener('submit', function (event) {
        event.preventDefault();
        var v = readForm(form);
        renderCustom(v.servers, v.workers, v.ingress);
      });
      form.addEventListener('input', function () {
        var steps = document.querySelector('[data-cs-steps="custom"]');
        if (steps && steps.hasAttribute('hidden')) return;
        var v = readForm(form);
        renderCustom(v.servers, v.workers, v.ingress);
      });
    }

    function wireReset() {
      var btn = document.getElementById('cs-reset');
      if (!btn) return;
      btn.addEventListener('click', function () {
        try { localStorage.removeItem(STORAGE_KEY); } catch (e) {}
        applyProgress();
      });
    }

    function init() {
      wireSelect();
      wireCustomForm();
      wireReset();
      wireCheckboxes();
      applyProgress();
    }

    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', init);
    } else {
      init();
    }
  })();
`}</script>
