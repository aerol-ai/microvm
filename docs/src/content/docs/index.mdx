## What Ships

This repository packages two binaries:

- `sandboxd`: the host daemon that manages Docker, persisted state, public routing, and the REST API.
- `toolboxd`: a lightweight in-container process mounted into each sandbox to provide health, command execution, file transfer, and local port proxying.

## Core Capabilities

- Create, list, inspect, start, stop, destroy, and resize sandboxes.
- Expose container ports publicly through dynamic Caddy routes.
- Proxy toolbox traffic through the host API.
- Persist sandbox state in SQLite and reconcile it on restart.
- Mount external storage without placing credentials inside containers.
- Stream command execution with optional PTY support.
