import { Tabs, TabItem } from '@astrojs/starlight/components';

[Codex CLI](https://github.com/openai/codex) is OpenAI's open-source coding agent for the terminal. It calls OpenAI models with your OpenAI API key.

In this recipe Codex CLI runs inside a sandbox, on a copy of a GitHub repository. It makes one change you describe in plain words, and you download that change as a patch: a file that lists every changed line. The agent can install tools and run commands there without touching your machine.

The agent runs in a [session](/sessions/). A session keeps running when your program stops or your connection drops, so a long task is never cut off halfway.

## What you need

- An AerolVM server and an SDK for your language. See [SDK setup](/sdk-setup/).
- These environment variables on your computer:

| Variable | What it is | Default |
|---|---|---|
| `SB_API_URL` | The address of your AerolVM server. | `http://127.0.0.1:21212` |
| `SB_PAT_TOKEN` | Your AerolVM token. | None. You must set it. |
| `OPENAI_API_KEY` | Your OpenAI API key. The sandbox gets it as `CODEX_API_KEY`, the name `codex exec` reads. | None. You must set it. |

```bash
export SB_API_URL=http://localhost:21212
export SB_PAT_TOKEN=your-secret-pat
export OPENAI_API_KEY=your-key
```

## Step 1: Create the sandbox

Codex CLI installs from npm, so the sandbox starts from a Node.js image. It also has Git. The API key goes in as an environment variable, so it never appears in a command. The lifecycle rule deletes the sandbox after 30 idle minutes, in case your program stops early.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    const sandbox = await client.create({
      image: "node:22-bookworm",
      cpu: 1,
      memoryMB: 2048,
      env: { CODEX_API_KEY: process.env.OPENAI_API_KEY! },
      lifecycle: { destroyIfIdleFor: 30 * 60 * 1_000_000_000 }, // 30 minutes
    });
    console.log(sandbox.id);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os

    sandbox = client.create(
        image="node:22-bookworm",
        cpu=1,
        memoryMB=2048,
        env={"CODEX_API_KEY": os.environ["OPENAI_API_KEY"]},
        lifecycle={"destroyIfIdleFor": 30 * 60 * 1_000_000_000},  # 30 minutes
    )
    print(sandbox.id)
    ```
  </TabItem>
  <TabItem label="Go">
    ```go

        Image:     "node:22-bookworm",
        CPU:       1,
        MemoryMB:  2048,

        Lifecycle: &sdktypes.Lifecycle{DestroyIfIdleFor: 30 * time.Minute},
    })

        log.Fatal(err)
    }
    fmt.Println(sandbox.ID)
    ```
  </TabItem>
  <TabItem label="Rust">

  </TabItem>
  <TabItem label="Java">
    ```java

        .setMemoryMb(2048)

        .setLifecycle(new Lifecycle().setDestroyIfIdleFor(Duration.ofMinutes(30).toNanos())));
    System.out.println(sandbox.id);
    ```
  </TabItem>
</Tabs>

Keep the sandbox ID it prints. You need it to come back later.

## Step 2: Install Codex CLI and clone the repository

This installs Codex CLI at a fixed version and clones the repository into `/workspace/repo`. It fetches only the latest commit, which is faster.

## Step 3: Start Codex CLI in a session

The task goes in as the environment variable `TASK`, so quotes and other special characters in it are safe. The session starts in the repository's folder and returns at once. Codex CLI keeps working in the sandbox.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    const session = await sandbox.createSession({
      name: "codex",
      command: 'codex exec --dangerously-bypass-approvals-and-sandbox "$TASK" < /dev/null',
      workDir: "/workspace/repo",
      env: { TASK: "Add a section to README.md that explains how to run the tests. Change no other file." },
    });
    console.log(session.id);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    session = sandbox.create_session({
        "name": "codex",
        "command": 'codex exec --dangerously-bypass-approvals-and-sandbox "$TASK" < /dev/null',
        "workDir": "/workspace/repo",
        "env": {"TASK": "Add a section to README.md that explains how to run the tests. Change no other file."},
    })
    print(session["id"])
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    session, err := sandbox.CreateSession(ctx, sdktypes.CreateSessionOptions{
        Name:    "codex",
        Command: `codex exec --dangerously-bypass-approvals-and-sandbox "$TASK" < /dev/null`,
        WorkDir: "/workspace/repo",
    ```

  </TabItem>
  <TabItem label="Rust">

    ```rust
            "Add a section to README.md that explains how to run the tests. Change no other file.".to_string(),
        )])),
        ..Default::default()
    })?;
    println!("{}", session.id);
    ```
  </TabItem>
  <TabItem label="Java">
    ```java

        .setName("codex")
        .setCommand("codex exec --dangerously-bypass-approvals-and-sandbox \"$TASK\" < /dev/null")
        .setWorkDir("/workspace/repo")
        .setEnv(Map.of("TASK", "Add a section to README.md that explains how to run the tests. Change no other file.")));
    System.out.println(session.id);
    ```
  </TabItem>
</Tabs>

What the command does:

- `codex exec` runs one task with no chat window and exits when it is done.
- `< /dev/null` gives it an empty input. A session keeps the program's input open, and `codex exec` waits for that input to end before it starts, so without this it never starts.
- `--dangerously-bypass-approvals-and-sandbox` turns off Codex's approval prompts and its own sandbox. Codex's help says the flag is meant for places that are already sandboxed, which is what an AerolVM sandbox is.

## Step 4: Wait for it to finish

This checks the session every 10 seconds until Codex CLI exits, then prints what it wrote.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    let s = await sandbox.getSession(session.id);
    while (s.status === "running") {
      await new Promise((resolve) => setTimeout(resolve, 10_000));
      s = await sandbox.getSession(session.id);
    }
    console.log(new TextDecoder().decode(await sandbox.sessionLog(session.id)));
    console.log(s.status, s.exitCode);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import time

    s = sandbox.get_session(session["id"])
    while s["status"] == "running":
        time.sleep(10)
        s = sandbox.get_session(session["id"])
    print(sandbox.session_log(session["id"]).decode())
    print(s["status"], s["exitCode"])
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    s, err := sandbox.GetSession(ctx, session.ID)
    for err == nil && s.Status == sdktypes.SessionStatusRunning {
        time.Sleep(10 * time.Second)
        s, err = sandbox.GetSession(ctx, session.ID)
    }
    if err != nil {
        log.Fatal(err)
    }
    out, err := sandbox.SessionLog(ctx, session.ID)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(string(out))
    fmt.Println(s.Status, s.ExitCode)
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    use aerolvm_sdk::SessionStatus;

    let mut s = sandbox.get_session(&session.id)?;
    while s.status == SessionStatus::Running {
        std::thread::sleep(std::time::Duration::from_secs(10));
        s = sandbox.get_session(&session.id)?;
    }
    println!("{}", String::from_utf8_lossy(&sandbox.session_log(&session.id)?));
    println!("{:?} {}", s.status, s.exit_code);
    ```
  </TabItem>
  <TabItem label="Java">
    ```java
    Session s = sandbox.getSession(session.id);
    while ("running".equals(s.status)) {
        Thread.sleep(10_000);
        s = sandbox.getSession(session.id);
    }
    System.out.println(new String(sandbox.sessionLog(session.id), StandardCharsets.UTF_8));
    System.out.println(s.status + " " + s.exitCode);
    ```
  </TabItem>
</Tabs>

`exited` with exit code `0` means Codex CLI finished the task.

**If your program stops before this,** Codex CLI keeps working. Run this step later with the IDs you kept: get the sandbox with `client.get(sandboxId)` (Go `client.Get(ctx, sandboxId)`), then check the session as above. To watch the output live instead, attach to the session; see [Terminal sessions](/sessions/).

## Step 5: Download the change and clean up

This collects every change in the repository as a patch, downloads it, and deletes the sandbox.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    import { writeFile } from "node:fs/promises";

    await sandbox.exec("cd /workspace/repo && git add -A && git diff --cached > /tmp/agent.patch");
    await writeFile("agent.patch", await sandbox.downloadFile("/tmp/agent.patch"));
    await sandbox.destroy();
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    sandbox.exec("cd /workspace/repo && git add -A && git diff --cached > /tmp/agent.patch")
    with open("agent.patch", "wb") as f:
        f.write(sandbox.download_file("/tmp/agent.patch"))
    sandbox.destroy()
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    if _, err := sandbox.ExecCommand(ctx, "cd /workspace/repo && git add -A && git diff --cached > /tmp/agent.patch"); err != nil {
        log.Fatal(err)
    }
    patch, err := sandbox.DownloadFile(ctx, "/tmp/agent.patch")
    if err != nil {
        log.Fatal(err)
    }
    if err := os.WriteFile("agent.patch", patch, 0o644); err != nil {
        log.Fatal(err)
    }
    if err := sandbox.Destroy(ctx); err != nil {
        log.Fatal(err)
    }
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    sandbox.exec("cd /workspace/repo && git add -A && git diff --cached > /tmp/agent.patch")?;
    let patch = sandbox.download_file("/tmp/agent.patch")?;
    std::fs::write("agent.patch", patch).expect("write agent.patch");
    sandbox.destroy()?;
    ```
  </TabItem>
  <TabItem label="Java">
    ```java
    sandbox.exec("cd /workspace/repo && git add -A && git diff --cached > /tmp/agent.patch");
    Files.write(Path.of("agent.patch"), sandbox.downloadFile("/tmp/agent.patch"));
    sandbox.destroy();
    ```
  </TabItem>
</Tabs>

Apply the patch to your own copy of the repository with `git apply agent.patch`.

## Good to know

- **The key's name matters.** `codex exec` reads its API key from `CODEX_API_KEY`. Passed as `OPENAI_API_KEY`, it fails with `401 Unauthorized`.
- **Another model.** Add `-m` and a model name to the command.
- **Codex wants a Git repository.** The cloned repository is one. To run it in a plain folder, add `--skip-git-repo-check`.
- **The agent can read every environment variable you pass,** including its API key. Use a key with a spending limit.
- **The sandbox can reach the internet,** which the agent needs for its model and for packages. To allow only the hosts it needs, see [Allow only some websites](/network-access/#allow-only-some-websites).
- **The session log keeps the last 1 MB** of output. For everything, download the session's recording with `sessionRecording`; see [Terminal sessions](/sessions/#recordings).
- **Lifecycle times are in nanoseconds,** except in Go, which takes a `time.Duration`.
