title: Run Aider in a sandbox
description: Run the Aider coding agent headless in a sandbox, in a session that keeps going if your connection drops, and download its change as a patch.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

[Aider](https://aider.chat) is an open-source coding agent that edits the files of a Git repository. It works with many model providers. This recipe uses Claude through your Anthropic API key.

In this recipe Aider runs inside a sandbox, on a copy of a GitHub repository. It makes one change you describe in plain words, and you download that change as a patch: a file that lists every changed line. The agent can install tools and run commands there without touching your machine.

The agent runs in a [session](/sessions/). A session keeps running when your program stops or your connection drops, so a long task is never cut off halfway.

## What you need

- An AerolVM server and an SDK for your language. See [SDK setup](/sdk-setup/).
- These environment variables on your computer:

| Variable | What it is | Default |
|---|---|---|
| `SB_API_URL` | The address of your AerolVM server. | `http://127.0.0.1:21212` |
| `SB_PAT_TOKEN` | Your AerolVM token. | None. You must set it. |
| `ANTHROPIC_API_KEY` | Your Anthropic API key. Aider uses it to call Claude. | None. You must set it. |

```bash
export SB_API_URL=http://localhost:21212
export SB_PAT_TOKEN=your-secret-pat
export ANTHROPIC_API_KEY=your-key
```

## Step 1: Create the sandbox

Aider is a Python program and needs Python 3.10 to 3.12, so the sandbox starts from a Python 3.12 image. It also has Git. The API key goes in as an environment variable, so it never appears in a command. The lifecycle rule deletes the sandbox after 30 idle minutes, in case your program stops early.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    const sandbox = await client.create({
      image: "python:3.12-bookworm",
      cpu: 1,
      memoryMB: 2048,
      env: { ANTHROPIC_API_KEY: process.env.ANTHROPIC_API_KEY! },
      lifecycle: { destroyIfIdleFor: 30 * 60 * 1_000_000_000 }, // 30 minutes
    });
    console.log(sandbox.id);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os

    sandbox = client.create(
        image="python:3.12-bookworm",
        cpu=1,
        memoryMB=2048,
        env={"ANTHROPIC_API_KEY": os.environ["ANTHROPIC_API_KEY"]},
        lifecycle={"destroyIfIdleFor": 30 * 60 * 1_000_000_000},  # 30 minutes
    )
    print(sandbox.id)
    ```
  </TabItem>
  <TabItem label="Go">

    ```java
    System.out.println(sandbox.id);
    ```

Keep the sandbox ID it prints. You need it to come back later.

## Step 2: Install Aider and clone the repository

This installs Aider at a fixed version and clones the repository into `/workspace/repo`. It fetches only the latest commit, which is faster.

<Tabs syncKey="lang">

    ```ts
      command: "pip install --no-cache-dir aider-chat==0.86.2 && git clone --depth=1 https://github.com/sindresorhus/slugify /workspace/repo",
      timeoutSeconds: 300,
    });
    if (setup.exitCode !== 0) throw new Error(setup.stderr);
    ```
  </TabItem>

## Step 3: Start Aider in a session

The task goes in as the environment variable `TASK`, so quotes and other special characters in it are safe. The session starts in the repository's folder and returns at once. Aider keeps working in the sandbox.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    const session = await sandbox.createSession({
      name: "aider",
      command: 'aider --model anthropic/claude-sonnet-4-6 --message "$TASK" --yes-always --no-auto-commits --no-check-update --no-show-model-warnings --no-gitignore --no-pretty --no-analytics',
      workDir: "/workspace/repo",
      env: { TASK: "Add a section to README.md that explains how to run the tests. Change no other file." },
    });
    console.log(session.id);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    session = sandbox.create_session({
        "name": "aider",
        "command": 'aider --model anthropic/claude-sonnet-4-6 --message "$TASK" --yes-always --no-auto-commits --no-check-update --no-show-model-warnings --no-gitignore --no-pretty --no-analytics',
        "workDir": "/workspace/repo",
        "env": {"TASK": "Add a section to README.md that explains how to run the tests. Change no other file."},
    })
    print(session["id"])
    ```
  </TabItem>
  <TabItem label="Go">

    ```go
        WorkDir: "/workspace/repo",
    ```

  </TabItem>
  <TabItem label="Java">
    ```java

        .setName("aider")
        .setCommand("aider --model anthropic/claude-sonnet-4-6 --message \"$TASK\" --yes-always --no-auto-commits --no-check-update --no-show-model-warnings --no-gitignore --no-pretty --no-analytics")
        .setWorkDir("/workspace/repo")
        .setEnv(Map.of("TASK", "Add a section to README.md that explains how to run the tests. Change no other file.")));
    System.out.println(session.id);
    ```
  </TabItem>
</Tabs>

What the command does:

- `--message` runs one task and exits, with no chat window.
- `--yes-always` answers yes to each question Aider asks, such as adding a file to the chat.
- `--no-auto-commits` leaves the change uncommitted, so step 5 can collect it with `git diff`. Without it, Aider commits each change itself.
- `--no-gitignore` stops Aider from adding its own files to `.gitignore`, so the patch holds only the agent's change.
- The other flags turn off the update check, model warnings, colors and usage reporting, which only matter in a terminal.

## Step 4: Wait for it to finish

This checks the session every 10 seconds until Aider exits, then prints what it wrote.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    let s = await sandbox.getSession(session.id);
    while (s.status === "running") {
      await new Promise((resolve) => setTimeout(resolve, 10_000));
      s = await sandbox.getSession(session.id);
    }
    console.log(new TextDecoder().decode(await sandbox.sessionLog(session.id)));
    console.log(s.status, s.exitCode);
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import time

    s = sandbox.get_session(session["id"])
    while s["status"] == "running":
        time.sleep(10)
        s = sandbox.get_session(session["id"])
    print(sandbox.session_log(session["id"]).decode())
    print(s["status"], s["exitCode"])
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    s, err := sandbox.GetSession(ctx, session.ID)
    for err == nil && s.Status == sdktypes.SessionStatusRunning {
        time.Sleep(10 * time.Second)
        s, err = sandbox.GetSession(ctx, session.ID)
    }
    if err != nil {
        log.Fatal(err)
    }
    out, err := sandbox.SessionLog(ctx, session.ID)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(string(out))
    fmt.Println(s.Status, s.ExitCode)
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    use aerolvm_sdk::SessionStatus;

    let mut s = sandbox.get_session(&session.id)?;
    while s.status == SessionStatus::Running {
        std::thread::sleep(std::time::Duration::from_secs(10));
        s = sandbox.get_session(&session.id)?;
    }
    println!("{}", String::from_utf8_lossy(&sandbox.session_log(&session.id)?));
    println!("{:?} {}", s.status, s.exit_code);
    ```
  </TabItem>
  <TabItem label="Java">
    ```java
    Session s = sandbox.getSession(session.id);
    while ("running".equals(s.status)) {
        Thread.sleep(10_000);
        s = sandbox.getSession(session.id);
    }
    System.out.println(new String(sandbox.sessionLog(session.id), StandardCharsets.UTF_8));
    System.out.println(s.status + " " + s.exitCode);
    ```
  </TabItem>
</Tabs>

`exited` with exit code `0` means Aider finished the task.

**If your program stops before this,** Aider keeps working. Run this step later with the IDs you kept: get the sandbox with `client.get(sandboxId)` (Go `client.Get(ctx, sandboxId)`), then check the session as above. To watch the output live instead, attach to the session; see [Terminal sessions](/sessions/).

## Step 5: Download the change and clean up

This collects every change in the repository as a patch, downloads it, and deletes the sandbox. Aider keeps its chat history and caches in `.aider*` files in the repository, and `--no-gitignore` stops it from hiding them, so the patch leaves them out.

<Tabs syncKey="lang">
  <TabItem label="TypeScript">
    ```ts
    import { writeFile } from "node:fs/promises";

    await sandbox.exec("cd /workspace/repo && git add -A -- . ':(exclude).aider*' && git diff --cached > /tmp/agent.patch");
    await writeFile("agent.patch", await sandbox.downloadFile("/tmp/agent.patch"));
    await sandbox.destroy();
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    sandbox.exec("cd /workspace/repo && git add -A -- . ':(exclude).aider*' && git diff --cached > /tmp/agent.patch")
    with open("agent.patch", "wb") as f:
        f.write(sandbox.download_file("/tmp/agent.patch"))
    sandbox.destroy()
    ```
  </TabItem>
  <TabItem label="Go">
    ```go
    if _, err := sandbox.ExecCommand(ctx, "cd /workspace/repo && git add -A -- . ':(exclude).aider*' && git diff --cached > /tmp/agent.patch"); err != nil {
        log.Fatal(err)
    }
    patch, err := sandbox.DownloadFile(ctx, "/tmp/agent.patch")
    if err != nil {
        log.Fatal(err)
    }
    if err := os.WriteFile("agent.patch", patch, 0o644); err != nil {
        log.Fatal(err)
    }
    if err := sandbox.Destroy(ctx); err != nil {
        log.Fatal(err)
    }
    ```
  </TabItem>
  <TabItem label="Rust">
    ```rust
    sandbox.exec("cd /workspace/repo && git add -A -- . ':(exclude).aider*' && git diff --cached > /tmp/agent.patch")?;
    let patch = sandbox.download_file("/tmp/agent.patch")?;
    std::fs::write("agent.patch", patch).expect("write agent.patch");
    sandbox.destroy()?;
    ```
  </TabItem>
  <TabItem label="Java">
    ```java
    sandbox.exec("cd /workspace/repo && git add -A -- . ':(exclude).aider*' && git diff --cached > /tmp/agent.patch");
    Files.write(Path.of("agent.patch"), sandbox.downloadFile("/tmp/agent.patch"));
    sandbox.destroy();
    ```
  </TabItem>
</Tabs>

Apply the patch to your own copy of the repository with `git apply agent.patch`.

## Good to know

- **Another model.** Change `--model` and pass that provider's key in step 1 instead, such as `OPENAI_API_KEY` for `gpt-...` models.
- **The agent can read every environment variable you pass,** including its API key. Use a key with a spending limit.
- **The sandbox can reach the internet,** which the agent needs for its model and for packages. To allow only the hosts it needs, see [Allow only some websites](/network-access/#allow-only-some-websites).
- **The session log keeps the last 1 MB** of output. For everything, download the session's recording with `sessionRecording`; see [Terminal sessions](/sessions/#recordings).
- **Lifecycle times are in nanoseconds,** except in Go, which takes a `time.Duration`.
