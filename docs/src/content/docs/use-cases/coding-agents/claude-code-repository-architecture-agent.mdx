---
title: Generate an architecture diagram
description: Have Claude Code read a GitHub repository in a sandbox and write arch.md, a diagram and guide to how the code fits together.
---

In this project you point Claude Code at a GitHub repository and get back a file called `arch.md`. It holds a Mermaid diagram (a text format that draws flowcharts) and a short guide to the main parts of the code. It helps when you join a new codebase, check a project before you depend on it, or hand a repository to another team.

Claude Code runs inside a small sandbox. It can clone and read the code there without touching your machine.

## What you need

- An AerolVM server and Node.js 22 or newer. See [Quickstart](/quick-start/).
- These environment variables:

| Variable | What it is | Default |
|---|---|---|
| `SB_API_URL` | The address of your AerolVM server. | `http://127.0.0.1:21212` |
| `SB_PAT_TOKEN` | Your AerolVM token. | None. You must set it. |
| `ANTHROPIC_API_KEY` | Your Anthropic API key. Claude Code uses it to call the model. | None. You must set it. |
| `GITHUB_TOKEN` | A GitHub token that can read the repository. | None. You must set it. |
| `ANTHROPIC_MODEL` | The Claude model to use. | `claude-sonnet-4-6` |

## Build it

### Step 1: Set up a project

```bash
mkdir arch-agent && cd arch-agent
npm init -y
npm install @aerol-ai/aerolvm-sdk
```

### Step 2: Set your keys

```bash
export SB_API_URL=http://localhost:21212
export SB_PAT_TOKEN=your-secret-pat
export ANTHROPIC_API_KEY=your-anthropic-key
export GITHUB_TOKEN=your-github-token
```

### Step 3: Save the script

Save this as `architecture-agent.ts`. To read a different repository, change `repoSlug`.

```ts
import { MicroVM, type Sandbox } from "@aerol-ai/aerolvm-sdk";
import { writeFile } from "node:fs/promises";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:21212";
const patToken = requireEnv("SB_PAT_TOKEN");
const anthropicApiKey = requireEnv("ANTHROPIC_API_KEY");
const githubToken = requireEnv("GITHUB_TOKEN");
const anthropicModel = process.env.ANTHROPIC_MODEL ?? "claude-sonnet-4-6";

const repoSlug = "open-telemetry/opentelemetry-collector";
const claudeSettings = JSON.stringify(
  {
    $schema: "https://json.schemastore.org/claude-code-settings.json",
    model: anthropicModel,
  },
  null,
  2,
);

const claudeProjectMemory = `# Claude Code instructions for this run

You are running inside an AerolVM sandbox.

- Focus on architecture, subsystem boundaries, and request flow.
- Prefer a high-signal system diagram over file-by-file narration.
- Write the final artifact to arch.md.
- Do not edit any file other than arch.md.
`;

const claudeTask = `Create the architecture diagram of repository in arch.md.

Requirements:
- Write Markdown.
- Include exactly one Mermaid flowchart.
- Explain the main entrypoints, core packages, request flow, state and storage, and external integrations.
- Add a section named How to read this architecture with 5 bullets.
- Modify only arch.md.
`;

// Reads a required environment variable, or stops with a clear message.
function requireEnv(name: string): string {
  const value = process.env[name];
  if (!value) {
    throw new Error(`Set ${name} before running this example.`);
  }
  return value;
}

// Runs a command in the sandbox and shows its output as it happens.
// Stops the script if the command fails.
async function run(sandbox: Sandbox, command: string) {
  const handle = sandbox.execStream({
    command,
    onStdout: (chunk) => process.stdout.write(chunk),
    onStderr: (chunk) => process.stderr.write(chunk),
    onError: (message) => process.stderr.write(`${message}\n`),
  });
  const exit = await handle.done;
  if (exit.code !== 0) {
    throw new Error(`Command failed (exit ${exit.code}): ${command}`);
  }
}

async function main() {
  const client = new MicroVM({ apiUrl, patToken });
  const sandbox = await client.create({
    image: "node:22-bookworm",
    cpu: 0.5,
    memoryMB: 2048,
    diskGB: 16,
    env: {
      ANTHROPIC_API_KEY: anthropicApiKey,
      ANTHROPIC_MODEL: anthropicModel,
      GITHUB_TOKEN: githubToken,
      GH_TOKEN: githubToken,
    },
    lifecycle: {
      destroyIfIdleFor: 30 * 60 * 1_000_000_000, // 30 minutes, in nanoseconds
    },
  });

  try {
    await run(
      sandbox,
      [
        "apt-get update",
        "DEBIAN_FRONTEND=noninteractive apt-get install -y git gh curl ca-certificates",
        "curl -fsSL https://claude.ai/install.sh | bash",
        'export PATH="$HOME/.local/bin:$PATH"',
        "claude --version",
        "gh --version",
      ].join(" && "),
    );

    await run(
      sandbox,
      [
        "mkdir -p /workspace /workspace/out",
        "gh auth status -h github.com",
        `gh repo clone ${repoSlug} /workspace/repo -- --depth=1`,
        "mkdir -p /workspace/repo/.claude",
      ].join(" && "),
    );

    await sandbox.uploadFile(
      "/workspace/repo/.claude/settings.json",
      claudeSettings,
    );
    await sandbox.uploadFile(
      "/workspace/repo/CLAUDE.md",
      claudeProjectMemory,
    );

    const stdoutChunks: string[] = [];
    const stderrChunks: string[] = [];

    const claudeRun = sandbox.execStream({
      command: [
        'export PATH="$HOME/.local/bin:$PATH"',
        `claude --model "$ANTHROPIC_MODEL" --dangerously-skip-permissions -p '${claudeTask}'`,
        "git add --intent-to-add arch.md",
        "git diff -- arch.md > /workspace/out/architecture.patch",
      ].join(" && "),
      workdir: "/workspace/repo",
      onStdout: (chunk) => {
        const text = Buffer.from(chunk).toString("utf8");
        stdoutChunks.push(text);
        process.stdout.write(text);
      },
      onStderr: (chunk) => {
        const text = Buffer.from(chunk).toString("utf8");
        stderrChunks.push(text);
        process.stderr.write(text);
      },
      onError: (message) => {
        process.stderr.write(`${message}\n`);
      },
    });

    const exit = await claudeRun.done;
    if (exit.code !== 0) {
      throw new Error(`claude run failed with exit code ${exit.code}`);
    }

    const decoder = new TextDecoder();
    const architectureMarkdown = decoder.decode(
      await sandbox.downloadFile("/workspace/repo/arch.md"),
    );
    const patch = decoder.decode(
      await sandbox.downloadFile("/workspace/out/architecture.patch"),
    );

    await writeFile("repository-architecture.md", architectureMarkdown);
    await writeFile("repository-architecture.patch", patch);
    await writeFile(
      "repository-architecture-claude.log",
      `${stdoutChunks.join("")}\n${stderrChunks.join("")}`,
    );

    console.log("\n===== arch.md =====\n");
    console.log(architectureMarkdown);

    console.log(
      JSON.stringify(
        {
          sandboxID: sandbox.id,
          repo: repoSlug,
          model: anthropicModel,
          architectureFile: "repository-architecture.md",
          patchFile: "repository-architecture.patch",
          logFile: "repository-architecture-claude.log",
        },
        null,
        2,
      ),
    );
  } finally {
    await sandbox.destroy();
  }
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

### Step 4: Run it

```bash
npx tsx architecture-agent.ts
```

Claude Code's output streams to your terminal while it works. When it is done, the script prints `arch.md` and saves three files in your folder.

## What the script does

1. **Creates a sandbox** from the `node:22-bookworm` image with half a CPU core, 2 GB of memory and 16 GB of disk. A lifecycle rule deletes it after 30 idle minutes, in case your script stops early.
2. **Installs the tools:** Git, the GitHub command-line tool `gh`, and Claude Code. You see the install output live. If a command fails, the script stops.
3. **Clones the repository** with your GitHub token. It fetches only the latest commit (`--depth=1`), which is faster.
4. **Uploads two files.** `.claude/settings.json` picks the model. `CLAUDE.md` tells Claude Code what to focus on and to edit only `arch.md`.
5. **Runs Claude Code** with `execStream`, so you see its output live. The `--dangerously-skip-permissions` flag lets it work without stopping to ask you for approval.
6. **Downloads the results** and deletes the sandbox, even if a step failed.

## What you get

| File | What is in it |
|---|---|
| `repository-architecture.md` | The finished guide with its diagram. |
| `repository-architecture.patch` | Exactly what Claude Code added, as a Git diff. |
| `repository-architecture-claude.log` | Everything Claude Code printed, for checking and debugging. |

## Good to know

- Lifecycle times are in nanoseconds. `30 * 60 * 1_000_000_000` is 30 minutes.
- The script runs every step with `execStream`, not `exec`. In Node.js, one `exec` call can wait only about 5 minutes for its answer, because Node's built-in `fetch` stops waiting after that. A slow install can take longer.
- Claude Code can read every environment variable you pass in, including your GitHub token. Give it a token that can only read the repositories it needs.
- Large repositories take longer and use more model tokens, so they cost more.
