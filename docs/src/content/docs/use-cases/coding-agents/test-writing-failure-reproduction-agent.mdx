## What you are building

This example turns a concrete bug report into a deterministic failing test. It clones a public repository, creates a small reproduction folder inside it, runs the failing test, and exports both the test file and the failure transcript.

## Why AerolVM fits

- Fresh sandboxes remove local-machine drift from the reproduction process.
- A self-contained failing test makes the regression easy to share with another engineer or agent.
- Downloaded artifacts capture the exact failing test and reproduction transcript.

## Copy-paste TypeScript script

This script is self-contained. The only required environment variable is `SB_PAT_TOKEN`. If `SB_API_URL` is unset, the script defaults to `http://127.0.0.1:8080`.

```ts
import { MicroVM } from "@aerol-ai/aerolvm-sdk";
import { writeFile } from "node:fs/promises";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:8080";
const patToken = process.env.SB_PAT_TOKEN;

if (!patToken) {
  throw new Error("Set SB_PAT_TOKEN before running this example.");
}

const repoURL = "https://github.com/expressjs/express.git";
const bugReport = {
  title: "Health response should stay structured JSON",
  observed: "The function currently returns the string 'ok'.",
  expected: "The function should return { status: 'ok' }.",
};

const buggyModule = `export function buildHealthResponse() {
  return "ok";
}
`;

const failingTest = `import test from "node:test";
import assert from "node:assert/strict";
import { buildHealthResponse } from "./buggy-service.mjs";

test("health response stays structured JSON", () => {
  assert.deepEqual(buildHealthResponse(), { status: "ok" });
});
`;

async function main() {
  const client = new MicroVM({ apiUrl, patToken });
  const sandbox = await client.create({
    image: "node:22-bookworm",
    cpu: 1,
    memoryMB: 2048,
    diskGB: 12,
  });

  try {
    await sandbox.exec("apt-get update && apt-get install -y git");
    await sandbox.exec("mkdir -p /workspace/out");
    await sandbox.exec({
      command: `git clone --depth=1 ${repoURL} /workspace/app`,
    });
    await sandbox.exec("mkdir -p /workspace/app/aerolvm-repro");

    await sandbox.uploadFile(
      "/workspace/app/aerolvm-repro/bug-report.md",
      `# ${bugReport.title}\n\nObserved: ${bugReport.observed}\nExpected: ${bugReport.expected}\n`,
    );
    await sandbox.uploadFile(
      "/workspace/app/aerolvm-repro/buggy-service.mjs",
      buggyModule,
    );
    await sandbox.uploadFile(
      "/workspace/app/aerolvm-repro/repro.test.mjs",
      failingTest,
    );

    const result = await sandbox.exec({
      command: "node --test /workspace/app/aerolvm-repro/repro.test.mjs",
      timeoutSeconds: 30,
    });

    if (result.exitCode !== 1) {
      throw new Error(
        `expected a failing regression test, got exit code ${result.exitCode}`,
      );
    }

    const decoder = new TextDecoder();
    const testSource = decoder.decode(
      await sandbox.downloadFile("/workspace/app/aerolvm-repro/repro.test.mjs"),
    );
    const transcript = [result.stdout, result.stderr].filter(Boolean).join("\n");

    await writeFile("test-writing-failure-reproduction.test.mjs", testSource);
    await writeFile("test-writing-failure-reproduction.log", transcript);

    console.log(
      JSON.stringify(
        {
          sandboxID: sandbox.id,
          expectedFailure: true,
          testFile: "test-writing-failure-reproduction.test.mjs",
          logFile: "test-writing-failure-reproduction.log",
        },
        null,
        2,
      ),
    );
  } finally {
    await sandbox.destroy();
  }
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

## Deliverables

- `test-writing-failure-reproduction.test.mjs` with the exact failing test.
- `test-writing-failure-reproduction.log` with the failing output.
