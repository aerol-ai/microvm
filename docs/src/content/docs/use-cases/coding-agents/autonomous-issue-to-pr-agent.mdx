## What you are building

This example takes a specific engineering task and turns it into a reviewable patch. It clones a public repository, adds a contributor note with exact test instructions, validates the repository, and exports both the patch and a human-readable summary.

## Why AerolVM fits

- The cloned repository and generated patch stay isolated from the host machine.
- Streamed execution gives live progress while the automation installs dependencies and validates the repo.
- Files make it easy to move the generated artifact back to your machine.
- Lifecycle controls let you keep the sandbox alive while the validation run finishes.

## Copy-paste TypeScript script

This script is self-contained. The only required environment variable is `SB_PAT_TOKEN`. If `SB_API_URL` is unset, the script defaults to `http://127.0.0.1:8080`.

```ts
import { MicroVM } from "@aerol-ai/aerolvm-sdk";
import { writeFile } from "node:fs/promises";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:8080";
const patToken = process.env.SB_PAT_TOKEN;

if (!patToken) {
  throw new Error("Set SB_PAT_TOKEN before running this example.");
}

const repoURL = "https://github.com/expressjs/express.git";
const contributorNote = `# Contributor note for the AerolVM example

This file is added by the copy-paste issue-to-PR example.

## Exact validation steps
1. Run npm install from the repository root.
2. Run npm test from the repository root.
3. Export the resulting patch for review.
`;

async function main() {
  const client = new MicroVM({ apiUrl, patToken });
  const sandbox = await client.create({
    image: "node:22-bookworm",
    cpu: 2,
    memoryMB: 4096,
    diskGB: 20,
    containerCommand: ["sh", "-lc", "while true; do sleep 3600; done"],
    lifecycle: {
      destroyIfIdleFor: 30 * 60 * 1_000_000_000,
    },
  });

  try {
    await sandbox.exec("apt-get update && apt-get install -y git");
    await sandbox.exec("mkdir -p /workspace/out");
    await sandbox.exec({
      command: `git clone --depth=1 ${repoURL} /workspace/app`,
    });

    await sandbox.uploadFile(
      "/workspace/app/CONTRIBUTING-AEROLVM.md",
      contributorNote,
    );

    const run = sandbox.execStream({
      command: [
        "npm install",
        "npm test",
        "printf '%s\\n' 'Created CONTRIBUTING-AEROLVM.md' 'Validation: npm test passed' > /workspace/out/summary.txt",
        "git diff -- CONTRIBUTING-AEROLVM.md > /workspace/out/fix.patch",
      ].join(" && "),
      workdir: "/workspace/app",
      onStdout: (chunk) => process.stdout.write(chunk),
      onStderr: (chunk) => process.stderr.write(chunk),
    });

    const exit = await run.done;
    if (exit.code !== 0) {
      throw new Error(`automation failed with exit code ${exit.code}`);
    }

    const decoder = new TextDecoder();
    const patch = decoder.decode(
      await sandbox.downloadFile("/workspace/out/fix.patch"),
    );
    const summary = decoder.decode(
      await sandbox.downloadFile("/workspace/out/summary.txt"),
    );

    await writeFile("autonomous-issue-to-pr.patch", patch);
    await writeFile("autonomous-issue-to-pr-summary.txt", summary);

    console.log(
      JSON.stringify(
        {
          sandboxID: sandbox.id,
          patchFile: "autonomous-issue-to-pr.patch",
          summaryFile: "autonomous-issue-to-pr-summary.txt",
        },
        null,
        2,
      ),
    );
  } finally {
    await sandbox.destroy();
  }
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

## What to export

- `autonomous-issue-to-pr.patch` for review.
- `autonomous-issue-to-pr-summary.txt` for the delivery note.

## AerolVM primitives used

- `create`
- `exec` and `execStream`
- `uploadFile` and `downloadFile`
- `updateLifecycle` through the lifecycle policy on sandbox creation
