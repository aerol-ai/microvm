## What you are building

This is a concrete code-interpreter backend. A user submits a Python program, the product runs it in a disposable sandbox, and the backend returns stdout, stderr, exit status, and a generated artifact.

## Why AerolVM fits

- `runtime: "gvisor"` gives you a stronger isolation boundary for untrusted code.
- `networkBlockAll` keeps the run self-contained.
- `exec` works well for short-lived programs and returns structured output.

## Copy-paste TypeScript script

This script is self-contained. The only required environment variable is `SB_PAT_TOKEN`. If `SB_API_URL` is unset, the script defaults to `http://127.0.0.1:8080`.

```ts
import { MicroVM } from "@aerol-ai/aerolvm-sdk";
import { writeFile } from "node:fs/promises";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:8080";
const patToken = process.env.SB_PAT_TOKEN;

if (!patToken) {
  throw new Error("Set SB_PAT_TOKEN before running this example.");
}

const submittedPython = `from math import factorial

numbers = [3, 5, 7]
values = [factorial(number) for number in numbers]
print(",".join(str(value) for value in values))

with open("/workspace/run/output.txt", "w", encoding="utf-8") as handle:
    handle.write("factorials=" + ",".join(str(value) for value in values))
`;

async function main() {
  const client = new MicroVM({ apiUrl, patToken });
  const sandbox = await client.create({
    image: "python:3.12-bookworm",
    runtime: "gvisor",
    networkBlockAll: true,
    cpu: 1,
    memoryMB: 1024,
    diskGB: 8,
  });

  try {
    await sandbox.exec("mkdir -p /workspace/run");
    await sandbox.uploadFile("/workspace/run/main.py", submittedPython);

    const result = await sandbox.exec({
      command: "python /workspace/run/main.py",
      timeoutSeconds: 5,
    });

    if (result.exitCode !== 0) {
      throw new Error(`runner failed with exit code ${result.exitCode}`);
    }

    const artifact = new TextDecoder().decode(
      await sandbox.downloadFile("/workspace/run/output.txt"),
    );

    const payload = {
      stdout: result.stdout,
      stderr: result.stderr,
      exitCode: result.exitCode,
      artifact,
    };

    await writeFile(
      "embedded-code-runner-result.json",
      `${JSON.stringify(payload, null, 2)}\n`,
    );

    console.log(JSON.stringify(payload, null, 2));
  } finally {
    await sandbox.destroy();
  }
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

## Product outputs

- `embedded-code-runner-result.json` with stdout, stderr, exit code, and artifact contents.
- The generated artifact pulled back with `downloadFile`.
