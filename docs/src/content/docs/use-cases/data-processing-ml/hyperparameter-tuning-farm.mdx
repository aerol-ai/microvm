---
title: Hyperparameter tuning farm
description: Train the same model with different settings in several sandboxes at the same time, then compare the scores.
---

Hyperparameters are the settings you pick before you train a model, such as how many trees a random forest uses. Finding good ones means training many times and comparing the scores. This project runs each try in its own sandbox, all at the same time.

## Why use sandboxes for this

- **Faster.** The jobs run side by side. If your server has room for all of them, the whole search takes about as long as the slowest single job.
- **Separate.** If one training job crashes, the others keep going.
- **Fair.** Each sandbox has its own CPU and memory limits, so one job can't use more than its share.

## What you need

- An AerolVM server and Node.js 18 or newer. See [Quickstart](/quick-start/).
- `SB_PAT_TOKEN` set to your AerolVM token, and `SB_API_URL` if your server is not at `http://127.0.0.1:21212`.

The full project is also on GitHub: [hyperparameter-tuning-farm](https://github.com/aerol-ai/aerolvm-examples/tree/main/ml-data-engineering/hyperparameter-tuning-farm).

## Build it

### Step 1: Set up a project

```bash
mkdir tuning-farm && cd tuning-farm
npm init -y
npm install @aerol-ai/aerolvm-sdk
export SB_API_URL=http://localhost:21212
export SB_PAT_TOKEN=your-secret-pat
```

### Step 2: Save the script

Save this as `tuning-farm.ts`. It starts 3 sandboxes. Each one trains a scikit-learn random forest with a different `n_estimators` (number of trees) and reports its accuracy.

```ts
import { MicroVM } from "@aerol-ai/aerolvm-sdk";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:21212";
const patToken = process.env.SB_PAT_TOKEN;

const trainingScript = `
import os
import time
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

n_estimators = int(os.environ.get("N_ESTIMATORS", 10))
print(f"Training RandomForest with n_estimators={n_estimators}...")

# A fixed random_state gives every sandbox the same data, so the scores compare fairly.
X, y = make_classification(n_samples=1000, n_features=20, random_state=42)
clf = RandomForestClassifier(n_estimators=n_estimators)
scores = cross_val_score(clf, X, y, cv=5)

print(f"RESULT: accuracy={scores.mean():.4f}")
`;

async function trainModel(client: MicroVM, nEstimators: number) {
  console.log(`[Job n_estimators=${nEstimators}] Creating sandbox...`);
  const sandbox = await client.create({
    image: "python:3.11-bookworm",
    cpu: 1,
    memoryMB: 1024,
    env: { N_ESTIMATORS: String(nEstimators) }
  });
  console.log(`[Job n_estimators=${nEstimators}] Sandbox created: ${sandbox.id}`);

  try {
    console.log(`[Job n_estimators=${nEstimators}] Installing scikit-learn...`);
    await sandbox.exec("pip install scikit-learn");

    console.log(`[Job n_estimators=${nEstimators}] Uploading training script...`);
    await sandbox.uploadFile("/train.py", trainingScript);

    console.log(`[Job n_estimators=${nEstimators}] Running training script...`);
    const result = await sandbox.exec("python3 /train.py");
    console.log(`[Job n_estimators=${nEstimators}] Script finished (exit code: ${result.exitCode})`);

    const output = result.stdout.split("RESULT: ")[1]?.trim();
    return { nEstimators, output };
  } finally {
    // Delete the sandbox even if a step above failed.
    await sandbox.destroy();
    console.log(`[Job n_estimators=${nEstimators}] Sandbox destroyed.`);
  }
}

async function main() {
  if (!patToken) throw new Error("Set SB_PAT_TOKEN.");
  const client = new MicroVM({ apiUrl, patToken });
  const hyperparams = [10, 50, 100];

  console.log(`Spinning up ${hyperparams.length} parallel training jobs...`);

  const jobs = hyperparams.map(val => trainModel(client, val));
  const results = await Promise.all(jobs);

  console.log("\nAll training jobs completed successfully! Results:");
  console.table(results);
}

main().catch(console.error);
```

### Step 3: Run it

```bash
npx tsx tuning-farm.ts
```

The log lines from the three jobs mix together, because they run at the same time. At the end you see a table like this one, from a run on our test server. Your numbers may differ a little, because the forest itself uses randomness.

## What the script does

1. **Starts one job per setting.** `hyperparams` holds the values to try: 10, 50 and 100 trees. `Promise.all` runs the jobs at the same time and waits for all of them.
2. **Each job creates its own sandbox** from `python:3.11-bookworm` with 1 CPU core and 1 GB of memory. Its setting goes in as the `N_ESTIMATORS` environment variable.
3. **Installs scikit-learn and uploads the training program** to `/train.py`.
4. **Trains and scores the model.** The program makes a practice dataset, the same one in every sandbox. It trains with 5-fold cross-validation (it trains and tests 5 times on different slices of the data) and prints the average accuracy.
5. **Reads the score** from the line that starts with `RESULT:`, then deletes the sandbox.

## Try more settings

Add values to `hyperparams`, for example `[10, 50, 100, 200, 400]`. Each new value adds one sandbox, so make sure your server has room for all of them at once. To tune a different setting, pass it in `env` and read it in the Python program with `os.environ`.
