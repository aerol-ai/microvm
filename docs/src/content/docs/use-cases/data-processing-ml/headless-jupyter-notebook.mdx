JupyterLab is a web app for notebooks: pages where you mix Python code, its output and notes. In this project a sandbox installs a data science stack, starts JupyterLab, and gives you a link to open it in your browser. "Headless" means the sandbox has no screen of its own; you use it from your browser.

It gives you a clean place to explore a new dataset or library, without installing anything on your computer.

## Why use a sandbox for this

- **A fresh lab for every experiment.** Start a new one, try things, and delete it when you are done.
- **Your own stack.** Use an image that already has the versions of PyTorch, TensorFlow or JAX you want.
- **Locked with a token.** Only someone with both the link and the token can open the notebook.

## What you need

- An AerolVM server and Node.js 18 or newer. See [Quickstart](/quick-start/). On a server set up with a domain, the link works from anywhere. See [Install on a server](/getting-started/single-node-setup/).
- `SB_PAT_TOKEN` set to your AerolVM token, and `SB_API_URL` if your server is not at `http://127.0.0.1:21212`.
- Optional: `JUPYTER_TOKEN`, the token that unlocks the notebook. If you leave it out, the script makes a random one.

The full project is also on GitHub: [headless-jupyter-notebook](https://github.com/aerol-ai/aerolvm-examples/tree/main/ml-data-engineering/headless-jupyter-notebook).

## Build it

### Step 1: Set up a project

```bash
mkdir jupyter-sandbox && cd jupyter-sandbox
npm init -y
npm install @aerol-ai/aerolvm-sdk
export SB_API_URL=http://localhost:21212
export SB_PAT_TOKEN=your-secret-pat
```

### Step 2: Save the script

Save this as `jupyter.ts`.

```ts
import { randomBytes } from "node:crypto";
import { MicroVM } from "@aerol-ai/aerolvm-sdk";

const apiUrl = process.env.SB_API_URL ?? "http://127.0.0.1:21212";
const patToken = process.env.SB_PAT_TOKEN;
// The notebook is on a public link, so use a token nobody can guess.
const jupyterToken = process.env.JUPYTER_TOKEN ?? randomBytes(16).toString("hex");

async function main() {
  if (!patToken) throw new Error("Set SB_PAT_TOKEN.");
  const client = new MicroVM({ apiUrl, patToken });

  console.log("Creating Jupyter sandbox (1 CPU, 2GB RAM)...");
  const sandbox = await client.create({
    image: "python:3.11-bookworm",
    cpu: 1,
    memoryMB: 2048,
  });
  console.log(`Sandbox created: ${sandbox.id}`);

  try {
    console.log("Installing JupyterLab and the data science stack (this may take a minute)...");
    const install = await sandbox.exec("pip install jupyterlab pandas matplotlib polars");
    if (install.exitCode !== 0) {
      throw new Error(`pip install failed:\n${install.stderr}`);
    }

    console.log("Starting JupyterLab in a session...");
    await sandbox.createSession({
      name: "jupyter-server",
      command: `jupyter lab --ip=0.0.0.0 --port=8888 --no-browser --NotebookApp.token='${jupyterToken}' --allow-root`,
    });

    const exposure = await sandbox.exposePort(8888);

    console.log("\n--- JupyterLab Ready ---");
    console.log(`URL: ${exposure.url}?token=${jupyterToken}`);
    console.log("-------------------------\n");
    console.log(`When you are done, delete sandbox ${sandbox.id}.`);
  } catch (error) {
    // Setup failed: delete the sandbox so it does not keep running.
    await sandbox.destroy();
    throw error;
  }
}

main().catch(console.error);
```

### Step 3: Run it

```bash
npx tsx jupyter.ts
```

Open the printed URL in your browser. If the page does not load at first, wait a few seconds: JupyterLab takes a moment to start.

## What the script does

1. **Creates a sandbox** from `python:3.11-bookworm` with 1 CPU core and 2 GB of memory.
2. **Installs JupyterLab, pandas, matplotlib and Polars** with `pip`. If the install fails, the script deletes the sandbox and stops.
3. **Starts JupyterLab in a session**, a process that keeps running inside the sandbox after your script exits. JupyterLab listens on port 8888 and accepts only requests that carry the token. `--allow-root` is needed because the sandbox runs as the root user.
4. **Shares port 8888** with `exposePort` and prints the link, with the token added at the end.

## Use your own image

To start with your own libraries already installed, change `image` to an image that has them, such as one you built with PyTorch. Then remove those libraries from the `pip install` line. See [Images, resources and lifecycle](/environment/).

## Delete the sandbox when you are done

The sandbox keeps running until you delete it. Pass the ID the script printed:

```ts
import { MicroVM } from "@aerol-ai/aerolvm-sdk";

const client = new MicroVM(); // reads SB_API_URL and SB_PAT_TOKEN
client.destroy("sb-your-sandbox-id").then(() => console.log("Deleted."));
```

Your notebooks are deleted with it. Download any you want to keep first, from JupyterLab or with `downloadFile`. See [Files](/file-system/).
