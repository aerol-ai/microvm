## Vision

### 10x Check
"Provable containment" for agent sandboxes:
- `allow_out: ["pypi.org"]` means exactly that, including DNS: names outside
  the allowlist never leave the host, which closes the channel used in the
  September 2026 OpenAI escape and left open by Bedrock AgentCore and E2B's
  auto-allowed 8.8.8.8;
- a policy can be learned from a trusted run and locked;
- every denial for a hostname-filtered (gateway-mode) sandbox fails fast with
  a reason (DNS EDE "Blocked", HTTP 403, TLS `access_denied`, TCP reset or ICMP
  reject, typed WASM and isolate errors); block-all and quota blocks stay
  silent drops;
- no sandbox can spoof a neighbour;
- secrets can stay outside the sandbox (Phase 3, fully specified).

The DNS filter is the differentiator. The SNI proxy is table stakes that E2B
and Modal already ship.

## Accepted Scope (added to this plan)
- P0-2 widened: `CAP_NET_RAW` dropped for every docker and containerd sandbox.
- P1-13 explainable denials, fail fast on every path (Phase 1).
- A gateway → sandboxd audit event stream with a bounded buffer and a drop
  counter (spec review 1; required because the gateway is its own process).
- P2-7 learn mode: `network_egress_mode: "learn"` +
  `GET /v1/sandboxes/{id}/network/learned`, 5 SDKs + docs (Phase 2).
- P2-8 built-in profiles catalogue in `pkg/egresspolicy`, pinned at create,
  with one operator-run integration UC per profile running the real tool
  (Phase 2).
- Phase 2 wire contract: `network_egress_mode`, `egress_profiles`, profile
  CRUD (owner-scoped; `builtin:` reserved), union caps, owner-local fan-out,
  learn-mode storage and caps.
- P2-9 `POST /v1/network/policy/check`, 5 SDKs + docs (Phase 2).
- Phase 3 committed items, fully specified in plan §5.9 and still gated on
  demand:
  - P3-1 inspection with method/path rules;
  - P3-2 credential injection (per-host `{host, inject: {header, secret_ref}}`,
    where `secret_ref: "env:<KEY>"` is a key in the sandbox's own sealed env);
  - P3-3 per-binary rules (runc only).
