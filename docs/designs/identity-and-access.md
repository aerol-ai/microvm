## Vision

### 10x Check
The same build, with three additions, makes AerolVM the sandbox platform a security team signs off on in one meeting:
- named credentials enforced for people (SSO or a scoped token, never the shared token from outside the host), not just offered;
- a scrape credential that can read but never create, run or delete;
- quarterly access-review evidence from one command.

Each addition reuses the plan's principal, role and hash chain. None adds a store. MCP OAuth extends the same offline token check to MCP connectors such as claude.ai; ChatGPT is claimed once a live check passes.
