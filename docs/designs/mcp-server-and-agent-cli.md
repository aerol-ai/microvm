## Vision

### 10x Check
Today a coding agent can't use AerolVM without SDK code. The plan makes it one config line for local agents. 10x would be any agent, local or hosted, reaching a fresh AerolVM sandbox in one step and finding AerolVM wherever it looks for sandboxes. A remote endpoint, a plugin and a registry listing all reuse `internal/agentmcp`, so they cost roughly 2x the Phase 2 effort.

## Section findings resolved in the same review
- CF1: remote `/mcp` options are URL query parameters (`sandbox`, `create_if_missing`, `image`, `runtime`, `toolsets`, `read_only`).
- CF2: remote `/mcp` is pinned-only; a request without `sandbox=` returns 400.
- CF3: toolboxd kills an exec's process group when its stream drops before exit.
- CF5: the client verifies `?name=` results so an older sandboxd can't resolve the wrong sandbox.
- CF6: remote MCP ships with metrics, per-call logs and spans, a Grafana panel, an alert and a runbook.
- CF7: the per-owner index keeps the name `idx_sandboxes_name` so a rolled-back binary still boots.
