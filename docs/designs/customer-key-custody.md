## Vision

### 10x Check
"AerolVM never holds a key you cannot see or take back." A security reviewer
gets a custody report generated by each node, revocation takes effect across
the fleet in minutes instead of at the next restart, every unwrap made for a
request joins to a sandboxd audit event (background calls carry a fixed,
recognisable id), and customers can rotate and
retire key versions without breaking failover. The wrapping itself (the hard
part) was already in the plan; the 10x pieces are small surfaces on top.
