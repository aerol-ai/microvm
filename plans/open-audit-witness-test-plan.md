## Affected Pages/Routes
- Daemon boot (`sandboxd`, `pkg/daemon.Run`): witness resolution before the external-witness gate; enterprise mode boot with `SB_AUDIT_WITNESS_BACKEND=s3`.
- Witness ship loop (`internal/service/secret_audit_witness.go`, every backend): read before every ship (D23) and a daily re-ship of an unchanged head (D20).
- `aerolvm audit verify` (new CLI command): offline verification of witness history against local and exported chain records.
- No HTTP API routes change. `GET /v1/metrics` keeps reporting `aerolvm_secret_audit_witness_healthy`.

## Key Interactions to Verify
- Operator sets `SB_ENTERPRISE_MODE=true`, `SB_NODE_ID`, an off-node exporter and a witness bucket with Object Lock, versioning and a default retention ≥ `SB_SECRET_AUDIT_RETENTION_DAYS`; the release `sandboxd` boots on one server and on a 3-node cluster.
- Operator points the witness at an ordinary bucket (no versioning, no lock, no default rule, retention too short); boot refuses and the message names the fix.
- Operator's node role lacks `s3:ListBucket`; boot refuses at the missing-key probe and names the permission (D19).
- Witness S3 unreachable at boot; boot fails within 30 s and the error names the check and the bucket.
- S3 outage at run time; `aerolvm_secret_audit_witness_healthy` drops to 0, records keep landing locally, and the next ship catches up.
- Auditor runs `aerolvm audit verify --since <time>` from a laptop against the witness bucket, the export store (`--export` or `--export-dir`) and, optionally, a copy of the node's JSONL (`--local`); gets PASS with the window, FAIL naming the unlinked pair or the unreached head, or INCOMPLETE when the export has stalled (D22).

## Edge Cases
- Day rollover on a node that was down across midnight: today's key missing, newest day found with `ListObjectVersions` (with Delimiter).
  Value: protects=latest-head read after downtime; fails_when=fallback uses ListObjectsV2 or skips the day search; why_new=new layout (D2); seam=none
- Missing key with a role that lacks `s3:ListBucket`: the fake answers 403 (as S3 does), and `Open`'s probe of a random missing key refuses boot naming the permission; with the permission the fake answers 404 and the fallback runs.
  Value: protects=first boot on an empty bucket and boots after an idle midnight; fails_when=the IAM statement or the probe is dropped; why_new=D19; seam=none
- Delete marker on the newest day's key of an idle node returns an error and never falls back to the previous day.
  Value: protects=delete-marker-is-tamper rule under the day layout; fails_when=ListObjectsV2 hides the delete-marked day; why_new=C2 correction to D2; seam=none
- No versions under the node prefix at all returns ok=false (never recorded), not an error.
  Value: protects=empty-witness bootstrap for a fresh node; fails_when=NoSuchKey is surfaced as an error; why_new=new backend; seam=none
- `LastWitnessedHead("standalone")` returns ok=false and the fake sees no request; a `standalone` write is rejected.
  Value: protects=first boot from a foreign head under the legacy id; fails_when=the backend reads `node=standalone/`; why_new=D24; seam=none
- PUT without `x-amz-sdk-checksum-algorithm` and `x-amz-checksum-sha256` is rejected 400 by the fake, and the real client's PUT succeeds.
  Value: protects=uploads to locked buckets; fails_when=checksum config or ChecksumAlgorithm is dropped; why_new=interface fakes can't see headers (D12); seam=none
- Governance bucket where the node role holds bypass: canary delete with `x-amz-bypass-governance-retention: true` succeeds, so boot is refused.
  Value: protects=canary detects a deletable lock; fails_when=canary omits the bypass header; why_new=new canary rule (D7); seam=none
- Canary delete fails with a non-AccessDenied error (network, 500): boot is refused, not treated as safe.
  Value: protects=fail-closed canary; fails_when=any delete error is read as "denied"; why_new=new backend; seam=none
- Retention given in Years on the bucket default rule is converted before comparing with `SB_SECRET_AUDIT_RETENTION_DAYS`.
  Value: protects=boot check 3; fails_when=Years value compared as Days; why_new=new backend; seam=none
- `WitnessHeads` with 0 or 2 heads returns an error naming the one-head contract.
  Value: protects=defined failure semantics; fails_when=a loop is reintroduced; why_new=D11; seam=none
- Receipt has `ReceiptID = VersionId` and zero `RecordedAt`, so the service stores `ShippedAt`; exactly one request per changed-head ship.
  Value: protects=one-call ship path; fails_when=HeadObject is reintroduced; why_new=D10; seam=none
- `SB_AUDIT_WITNESS_BACKEND=s3` with `SB_NODE_ID` empty or `standalone` fails config load with a message naming `SB_NODE_ID`.
  Value: protects=no default-id collision across servers; fails_when=validation removed; why_new=D3; seam=none
- Unknown `SB_AUDIT_WITNESS_BACKEND` value fails config load; `s3` without a bucket fails config load; prefix without a trailing slash still produces `<prefix>/node=…`.
  Value: protects=config contract; fails_when=validation or path.Join is removed; why_new=new settings; seam=none
- Empty local chain with a remembered head: the boot error names the rebuild-under-a-new-SB_NODE_ID recovery.
  Value: protects=operator recovery path under Object Lock; fails_when=message reverts to "clear the witnessed head"; why_new=D4; seam=none
- Ship loop finds a head in the witness that this node did not ship (or none after a successful ship), on an idle tick and on a busy tick (head changed since the last ship): `aerolvm_secret_audit_witness_foreign_head_total` increments and a warning names both heads, then the loop ships; a matching head and a read error leave the counter alone.
  Value: protects=runtime visibility of foreign writes and duplicate node ids on every node; fails_when=the read stays inside the unchanged-head branch, or a read error is counted; why_new=D18, amended by D23; seam=none
- Unchanged head on the first tick of a new UTC day is re-shipped to today's key and not counted as foreign; a later tick that day does not re-ship.
  Value: protects=one-GET reads and a meaningful "silent" check for idle nodes; fails_when=the daily re-ship is dropped or repeats every tick; why_new=D20; seam=none
- `Open` against an endpoint that never answers returns within 30 s naming the check.
  Value: protects=bounded boot; fails_when=deadline removed; why_new=D9; seam=none
- Verifier export walk: an honest history passes across a retention prune in the middle of a day (offsets restart in the new generation), a batch re-sent after midnight, a re-export after a cursor reset, and a node id containing `_`.
  Value: protects=no false FAIL on honest histories; fails_when=batches are ordered by key or offset; why_new=D21 (supersedes D15's order rule); seam=none
- Verifier window: a head newer than `--since` that the evidence never reaches is FAIL, including when the oldest export batches inside the window were removed; a head older than `--since` is listed and not checked.
  Value: protects=the forged-tail attack that moves the evidence's starting point; fails_when=the window is taken from the evidence; why_new=D22; seam=none
- Verifier without `--local`: a head newer than the end of the evidence is pending; pending longer than `--max-lag` yields INCOMPLETE (exit 2), never PASS.
  Value: protects=a stalled export cannot hide a forged tail; fails_when=pending heads count as PASS; why_new=D22; seam=none
- Verifier ordering: two versions with the same `LastModified` second on one key keep S3's version order.
  Value: protects=no false rollback FAIL; fails_when=versions are sorted by LastModified alone; why_new=D22; seam=none
- Verifier silent check: a node idle for days (one daily version) is not silent; a node with no version for more than a day plus N intervals is.
  Value: protects=a usable silent-node list; fails_when=silence is measured in ship intervals; why_new=D20; seam=none
