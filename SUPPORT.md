# Support

## Scope and duration

Security fixes land on the most recent minor release line. That line is 0.6.x. A release on the supported line is supported until a newer minor line is published. Older patch releases on the same line are supported by upgrading to the newest patch. The project does not backport fixes onto a previous minor line.

## End of security updates

A release older than 0.6 no longer receives security updates. A minor line also stops receiving security updates once a newer minor line is published. Upgrade to the latest release on the supported line. The supported line is restated in [SECURITY.md](SECURITY.md) at each release so this page and that table stay the same.
